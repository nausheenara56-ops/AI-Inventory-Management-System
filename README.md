# AI-Driven Inventory Management System

A desktop inventory management application built with Python, Flet, and MongoDB.
Designed to help businesses track products, manage stock levels, and get
AI-powered insights for smarter inventory decisions.

## Features
- User authentication (login/signup)
- Add, Edit, Delete products
- Real-time stock tracking
- Low stock and out-of-stock alerts
- Dashboard with analytics and stats
- AI-powered demand forecasting
- Sales and purchase order management
- Category and supplier management
- Role-based admin panel

## Tech Stack
- Python 3.12
- Flet (cross-platform desktop UI)
- MongoDB + PyMongo (database)

## Project Structure
```
├── data/          # Database connection and services
├── dialogs/       # Add/Edit product dialogs
├── pages/         # All application pages
├── ui/            # UI components, theme, layout
└── main.py        # Entry point
```

## How to Run
1. Clone the repo:
   `git clone https://github.com/nausheenara56-ops/AI-Inventory-Management-System`
2. Install dependencies:
   `pip install flet pymongo`
3. Run the app:
   `python main.py`
