# Inventory Management System

A desktop inventory management application built with [Flet](https://flet.dev/) (Python), featuring AI-powered demand forecasting, smart reordering, and real-time alerts.

## Requirements

- Python 3.11+
- Flet

```bash
pip install flet
```

## Running the App

```bash
cd path/to/inventory_management_app && python main.py
```
